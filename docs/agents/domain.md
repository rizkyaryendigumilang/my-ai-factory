# Domain Documentation Configuration

## Context Layout
- **Layout Model:** Single-Context (Monorepo signals absent)
- **Primary Glossary:** `GLOSSARY.md` (root)
- **Architecture Decisions:** `docs/adr/` (numbered sequentially, e.g. `001-*.md`)

## Rules for Agents
1. Before proposing architecture changes or creating database collections, read `GLOSSARY.md`.
2. When creating new architectural patterns or introducing major dependencies, record an ADR in `docs/adr/`.
3. Adhere to ubiquitous language defined in `GLOSSARY.md`.
