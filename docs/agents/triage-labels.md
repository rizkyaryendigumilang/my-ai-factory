# Triage Label Vocabulary

Canonical 5-role triage label set for engineering skills:

| Label | Role / Meaning | When to Apply |
| :--- | :--- | :--- |
| `needs-triage` | Baru masuk / belum ditinjau | Diberikan otomatis pada issue yang baru dibuat sebelum diklasifikasi. |
| `needs-info` | Membutuhkan klarifikasi | Masalah belum jelas, kekurangan log error, atau kriteria penerimaan belum lengkap. |
| `ready-for-agent` | Siap dikerjakan oleh AI Agent | Spesifikasi jelas, blueprint tersedia, subagent Antigravity siap mengeksekusi. |
| `ready-for-human` | Membutuhkan tindakan Kiky | Memerlukan persetujuan arsitektur, rahasia/kredensial baru, atau review rilis. |
| `wontfix` | Di luar scope / ditolak | Tidak sesuai roadmap arsitektur atau melanggar prinsip anti-slop. |
